# 3D-Printed Robotic Dog Project

A simple 4-legged robotic dog project designed in Onshape. This project uses four SG90 micro servo motors and can be controlled using an ESP32 or Arduino Uno.

---

## Components Used

* Main Body (Chassis): Holds the motors and controller.
* Top Cover: Covers the electronics.
* 4 Legs: Custom 3D-printed parts for movement.
* 4 SG90 Micro Servo Motors: 1 motor for each leg.
* 4 Servo Horns: Connects the legs directly to the motors.
* Possible Microcontroller: ESP32 or Arduino Uno.

---

## Design & Assembly

The 3D model was created using Onshape. 

1. The four SG90 motors are placed inside the main body.
2. Servo horns are attached to the motor shafts.
3. Each leg is screwed into its servo horn.
4. The top cover is placed on top to protect the parts.
